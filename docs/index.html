OPERATION FLOW

起動順

  1. 1. 素材を揃える `public.html` または `assets.html` で `st_` `ct_` `tr_` を確認し、必要なデータを手元へ集めます。
  2. 2. 閲覧か編集かを選ぶ 表示確認だけなら `vewbasis.html`、編集作業に入るなら `edit.html` を起点にします。
  3. 3. 必要ならサムネを撮る `public_local_load.html` でワールドを読み込み、構図を決めてサムネイルへ反映します。

FILE GUIDE

素材の目印

  • st_~構造物データ。公開ワールドや編集再開の基礎になる本体。
  • ct_~都市モデル。街並みや背景オブジェクトの読み込み用。
  • tr_~列車モデル。車両フォルダまたは個別モデルとして扱う前提。
  • vewbasis.html旧 `index.html` の役割を引き継いだベース表示面。
