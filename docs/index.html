都市モデルと列車モデルを読み込むことで、同じ構造でも印象を切り替えられます。ローカルロードとの相性が良い構成です。

INSIDE THE BOX

同梱イメージ

製品で言えば「箱の中に何が入っているか」に相当する説明です。

  • 公開ワールド閲覧ページ: 配布済みワールドの確認と構造物データの取得。
  • モデルカタログ: 都市モデル `ct_` と車両モデル `tr_` の確認とダウンロード。
  • 編集ページ: 編集枠の選択、保存済みワールドの再開、サムネ撮影と公開導線。
  • 操作ガイド: PC / モバイルごとの基本操作の確認。
